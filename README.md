# FitQuest

FitQuest is a gamified calisthenics fitness application that transforms workout routines into an engaging video game experience. Users progress through levels, customize avatars, and earn rewards by completing bodyweight exercises consistently.

## Project Purpose

The goal of FitQuest is to motivate users to maintain consistent exercise habits by leveraging gamification mechanics. By making fitness progression feel like a video game, the application aims to increase user engagement and adherence to workout routines.

## Local Development

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Frontend Setup
```bash
cd client
npm install
npm run dev
```

The frontend will typically run on `http://localhost:5173`

### Backend Setup
```bash
cd api
npm install
npm start
```

The backend will run on `http://localhost:3001` by default
